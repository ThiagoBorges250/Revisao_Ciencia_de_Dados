# Revisao_Ciencia_de_Dados


## Sobre o projeto

Este repositório reúne uma atividade prática de Análise de Dados desenvolvida em Python, com foco no diagnóstico, na limpeza e na preparação de bases de dados. O trabalho está organizado em um notebook Jupyter/Google Colab, com etapas de exploração, tratamento e comparação dos dados antes e depois das transformações.

## Conteúdos abordados

- **Diagnóstico inicial:** análise das dimensões da base, tipos de dados, valores ausentes e registros duplicados.
- **Valores ausentes:** identificação, visualização de padrões e comparação de estratégias de tratamento.
- **Duplicatas:** identificação de duplicatas exatas e por subconjunto de colunas.
- **Padronização:** inspeção e normalização de valores e conversão de tipos de dados.
- **Escalonamento:** comparação entre Min-Max, Z-score e RobustScaler.
- **Outliers:** análise por estatísticas descritivas, Z-score, intervalo interquartil (IQR) e gráficos.
- **Projeto integrado:** aplicação de etapas de limpeza e preparação em uma base de dados.

## Tecnologias e bibliotecas

- Python
- Pandas
- NumPy
- Matplotlib
- Missingno
- Scikit-learn

## Arquivo principal

- `RevisaoCD.ipynb` — notebook contendo o código, as análises e as visualizações da atividade.

## Como executar

1. Baixe ou clone este repositório.
2. Abra o [Google Colab](https://colab.research.google.com/).
3. Importe o arquivo `RevisaoCD.ipynb`.
4. Instale as bibliotecas necessárias caso ainda não estejam disponíveis no ambiente.
5. Execute as células na ordem, do início ao fim.
6. Caso o notebook utilize arquivos CSV externos, coloque-os no local esperado pelo código ou atualize os caminhos de leitura.

## Objetivo

Praticar técnicas de análise exploratória, identificação de problemas de qualidade dos dados e preparação de bases para análises posteriores, documentando as decisões e comparando os resultados dos tratamentos realizados.

---

**Observação:** os resultados dependem das bases de dados utilizadas e da execução das células do notebook. Verifique os caminhos dos arquivos e as dependências antes de executar o projeto.
